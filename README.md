# JUDGE - AI Courtroom Verdict App

## What Is This?
A courtroom-themed AI app that analyzes conversations and disputes, delivering dramatic verdicts like a judge. Upload screenshots or paste text conversations, and receive a detailed analysis with winner/loser, credibility scores, manipulation tactics detected, and judicial recommendations.

## Status
**Complete** - All 11 features implemented and working.

## Tech Stack
- React 19 + Vite + TypeScript
- TailwindCSS for styling
- Google Gemini API for AI analysis
- IndexedDB for local case history
- Motion library for animations

## Getting Started
```bash
cd app
npm install
npm run dev
# Open http://localhost:5173
```

## Features
- Screenshot evidence upload (Exhibits A-J)
- Text conversation input with party names
- AI verdict with credibility scores, toxicity meter
- Manipulation tactics detection
- Shareable verdict cards (multiple themes)
- Case history saved locally

## Design
- Theme: "Law & Order meets Nuremberg" - dark, dramatic, official
- Colors: Black background, gold accents, red for warnings
